# ADR 0005 — Progreso visible y cortes verticales

## Estado

Aceptado

## Contexto

El desktop acumuló infraestructura antes de consolidar UX.

## Decisión

Cada fase entrega una mejora **visible, manipulable y comprensible** en la aplicación. El desarrollo avanza por **cortes verticales** (UI → comando → documento → geometría → vista), no por capas horizontales aisladas durante semanas.

## Consecuencias

- Etapa 0: app abrible sin modelado completo
- Etapa 1: un muro usable de punta a punta
- MVP: vivienda de muros dibujable
- Paradas humanas entre grandes etapas
