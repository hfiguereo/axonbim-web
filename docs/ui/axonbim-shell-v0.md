# Shell AxonBIM Web v0

**Base de interfaz futura:** ver [interface-base.md](interface-base.md) (aprobada 2026-08-06).

## Maqueta vs etapas

La maqueta replica la **distribución de productos de referencia** (cinta, paneles, navegador) para validar UX.  
La mayoría de botones son stub. Etapa 1 = corte vertical del **muro**, no paridad de cinta.

## Cinta

- Altura fija; iconos con tip corto al hover.
- Trazado (p. ej. Muro) → **Modificar | Colocar muro** + Dibujar + Cadena.
- Cadena de muro **on** por defecto; Soltar / Dividir en Modificar.
- Opciones de herramienta = renglón bajo la cinta.
- UI show/hide: **Gestionar → Interfaz**.

## Paneles

- Default: Propiedades + Navegador apilados a la **izquierda**.
- Acople **izq. / der. / flotante** (botones ◧ ▢ ◨ y drag a bordes).
- Ancho de columna y alto entre paneles redimensionables.

## Vista y chrome

- Planta → cámara ortogonal.
- Logo AxonBIM = menú Archivo.
- Barra inferior de vista: escala, estilo, detalle, render stub.
